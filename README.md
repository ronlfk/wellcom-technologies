# Wellcom Technologies LTD — website

A single-page static site for Wellcom Technologies LTD, a game studio.

## Running it

No build step and no dependencies. Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Structure

Everything lives in `index.html` — markup, styles, inline SVG icons and the theme toggle. External resources are limited to two Google Fonts (Space Grotesk, IBM Plex Sans).

Sections: hero · technology · studio culture · careers.

## Notes

The site carries no game titles, metrics or contact details. Those were removed on purpose — add them only once they can be backed up.
